Funciones principales

El sistema centraliza informacion importante para que el seguimiento sea mas ordenado, oportuno y facil de revisar.

01

Registro diario

Permite reportar sintomas, dolor, temperatura y cambios relevantes durante la recuperacion.

02

Seguimiento medico

Ayuda al personal medico a revisar la evolucion del paciente y tomar decisiones con mejor informacion.

03

Alertas tempranas

Facilita identificar posibles complicaciones postoperatorias para actuar a tiempo.

Como funciona

Un flujo sencillo para registrar informacion y mantener conectado al paciente con el equipo responsable.

1

Ingreso

El paciente accede al sistema con sus datos asignados.

2

Reporte

Registra sintomas, temperatura, dolor y observaciones.

3

Revision

El equipo medico revisa la informacion enviada.

4

Orientacion

Se brindan indicaciones o se activa atencion si hay alarma.

!

Atencion ante signos de alarma

Si presenta fiebre, dolor intenso, sangrado, dificultad para respirar o deterioro rapido, no espere una respuesta por el sistema y acuda a urgencias.
